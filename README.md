# B 站直播间弹幕自动发送

一个用于 B 站直播间的油猴脚本，可以自动发送弹幕。

## 功能特性

- 自动发送弹幕到 B 站直播间
- 支持多条弹幕循环发送（使用 `;` 分隔）
- 可拖动的控制面板
- 自定义发送间隔
- 实时显示发送次数

## 安装方法

1. 安装油猴插件（Tampermonkey 或 Violentmonkey）
2. 克隆或下载本项目
3. 运行构建命令生成脚本文件：
   ```bash
   npm run build
   ```
4. 将生成的 `dist/main.js` 文件内容复制到油猴插件中创建新脚本

## 使用方法

1. 访问任意 B 站直播间页面（如：https://live.bilibili.com/）
2. 脚本会自动加载，页面左上角会出现控制面板
3. 在输入框中输入要发送的弹幕内容，多条弹幕用 `;` 分隔
4. 点击"发送"按钮开始自动发送弹幕
5. 再次点击"停止"按钮可停止发送

## 配置说明

- **发送内容**：在输入框中输入弹幕，多条用 `;` 分隔，例如：`1;2;3;4;5`
- **发送间隔**：默认为 3500 毫秒（3.5 秒），可在代码中修改 `interval` 变量调整
- **面板位置**：可拖动标题栏移动控制面板位置
